# Matter Manipulator

Matter Manipulator is a RimWorld 1.6 mod that adds a late-game autonomous production building. The matter manipulator consumes a large amount of power, pulls feedstock from adjacent matter hoppers, and reconstructs it into a selected item.

## Features

- 3x3 autonomous matter manipulator building.
- Adjacent matter hopper for loading input resources.
- Converts input feedstock into selected items using configurable mass and time rules.
- Material selection for stuffable products.
- Quality selection with configurable work-time multipliers.
- Unique weapon trait selection, with extra work time for each chosen trait.
- One-time or infinite-repeat production modes.
- Optional result notifications.
- In-game mod settings for power, work speed, input mass factor, research cost, and quality multipliers.
- Localization: English, Russian, German, French, Spanish, Italian, Polish, Portuguese Brazilian, Turkish, Japanese, Korean, Simplified Chinese, and Traditional Chinese.

## Defaults

- Power consumption: 10000 W.
- Input requirement: 2x output mass.
- Work time: 8 in-game hours per kg of finished product.
- Research: Matter Manipulation, after Advanced Fabrication.

## Compatibility

Built for RimWorld 1.6.
